# 《战狗》玩家体验观察笔记：吸引力、体验分化与核心矛盾拆解

基于约 30 小时的个人游玩、身边玩家的体验，以及 B站、Steam、小黑盒等社区评价，尝试从玩法机制出发，分析《战狗》的初期吸引力与后续在线人数回落背后的可能原因。

[查看或下载完整报告（Word）](./wardogs-player-experience-notes.docx)

内容涵盖玩法分工、画面与手感、经济机制，以及时间负担、成长成本、对抗平衡、协作和游戏环境对继续游玩意愿的影响。

这是一份个人体验观察笔记。文中的机制解读与玩家偏好归纳包含作者判断，个人及社区观察不代表全体玩家；在线人数变化不能直接等同于留存率，也不能单独证明流失原因。
